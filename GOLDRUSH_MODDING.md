# Золотая лихорадка — документация по модам (API v1)

Эту страницу можно целиком отправить нейросети: «Вот API игры. Напиши мод, который …». Ответ нейросети — один JS-файл (или набор файлов для ZIP), который ставится на вкладке «Моды».

## 1. Что такое мод

Мод — обычный JavaScript-код (тело функции). Ему доступна одна переменная: `GoldRush` (API мода). Код выполняется один раз при запуске игры (и сразу после установки). Всё, что мод хочет добавить, он регистрирует вызовами `GoldRush.addXxx(...)`, а реакции на игру вешает через `GoldRush.on(событие, функция)`.

Моды хранятся в LocalStorage браузера. Включение, выключение, удаление и правка кода перезапускают игру (прогресс сохраняется).

### Форматы установки

Вкладка «Моды» принимает мод любым из способов: вставить код в поле; вставить в то же поле ссылку (`https://…/mod.js` или `…/mod.zip`); кнопка «По ссылке…»; кнопка «Файл…» (можно выбрать несколько `.js` и `.zip` сразу). Ссылка должна отдавать файл с разрешением CORS (например, GitHub raw).

1. **Один файл `.js`** — всё в одном файле, метаданные в комментариях `// @id …` (см. ниже).
2. **ZIP-архив** — для модов из нескольких файлов:
```
my_mod.zip
├─ mod.json          (необязателен) метаданные
├─ main.js           главный файл (или имя из поля "main")
├─ lib/util.js       любые модули
├─ data/items.json   данные
└─ img/ruby.png      картинки
```
`mod.json`: `{ "id": "my_mod", "name": "Мой мод", "version": "1.0", "author": "Я", "description": "…", "main": "main.js" }`. Если `mod.json` нет, главным считается `main.js` (или `index.js`, или единственный `.js`), а метаданные берутся из комментариев `// @…` в нём. Архив можно упаковать как со сжатием, так и без (Store). Пароль и ZIP64 не поддерживаются; лимит — 300 файлов, 8 МБ после распаковки; всё хранится в LocalStorage (около 5 МБ на сайт), поэтому картинки лучше делать маленькими.

В ZIP-моде доступны:
- `require('./lib/util.js')` — подключение своих модулей (CommonJS: внутри модуля `module.exports = …`; пути относительные; расширение `.js` можно опустить; `require('./data.json')` возвращает объект);
- `GoldRush.asset('img/ruby.png')` — картинка как data-URI (подходит для `icon: { texture: GoldRush.asset('img/ruby.png') }`, лучше 16×16 или 32×32 px);
- `GoldRush.text('path')`, `GoldRush.json('path')` — содержимое текстового файла / разобранный JSON;
- `GoldRush.files()` — список файлов архива.

Одинаковый `id` при повторной установке заменяет мод (обновление).

### Заголовок мода (необязателен, но рекомендуется)

Первые строки файла — комментарии в стиле userscript:

```js
// @id my_mod            // латиница/цифры/_, уникальный; повторная установка с тем же id заменяет мод
// @name Мой мод
// @version 1.0
// @author Имя
// @description Короткое описание
```

### Правила для автора мода (важно для нейросети)

1. Только чистый JS, без `import` и внешних библиотек. `require` можно использовать только для своих файлов внутри ZIP; одиночный `.js` самодостаточный.
2. Не обращаться к внутренностям игры (кроме `GoldRush.state` для чтения). Менять ресурсы только через `GoldRush.res.add/spend`.
3. НЕ менять `GoldRush.state.coins` и `GoldRush.state.gems` напрямую: встроенный античит расценит это как взлом и конфискует монеты. Монеты выдавать только через `GoldRush.res.add('coins', n)`.
4. Все id (предметов, блоков, рецептов, узлов) — латиница, цифры, `_`, 2–32 символа, начинаются с буквы. Используйте префикс мода: `ruby_gem`, `ruby_ore`.
5. Порядок: сначала `addItem`, потом `addBlock`/`addRecipe`/`addTreeNode`, которые на них ссылаются.
6. Ошибки внутри обработчиков не ломают игру: они пишутся в «Журнал ошибок» на вкладке «Моды».
7. Не делать тяжёлую работу в событиях `tick` (вызывается каждый кадр) — только лёгкие проверки.
8. Тексты для игрока — по-русски, коротко.

## 2. Быстрый пример

```js
// @id ruby
// @name Рубины
// @version 1.0
// @description Новая руда: рубин. Продаётся на рынке и крафтится в слиток.
const gr = GoldRush;

gr.addItem({ id: 'ruby_gem', name: 'Рубин', icon: { gem: '#e0115f' }, price: 90 });
gr.addItem({ id: 'ruby_bar', name: 'Рубиновый слиток', icon: { ingot: '#e0115f' }, price: 420 });

gr.addBlock({
  id: 'ruby_ore', name: 'Рубиновая руда', desc: 'рубины', icon: { ore: '#e0115f' },
  hp: 6, life: 2.8, xp: 12, minLevel: 3,
  weights: { '*': 4, deep: 8 },              // '*' — везде, 'deep' — в Глубинной шахте
  drops: { ruby_gem: [1, 2] },               // [мин, макс] или [мин, макс, шанс]
  coins: [8, 20]
});

gr.addRecipe({ id: 'ruby_bar_r', group: 'Моды', name: 'Рубиновый слиток',
  cost: { ruby_gem: 4, ingot: 1 }, out: 'ruby_bar', amount: 1, desc: '4 рубина + золотой слиток' });

gr.addTreeNode({ id: 'ruby_node', branch: 'Рубины', name: 'Глаз гранильщика', desc: '+10% урона',
  cost: { coins: 3000, ruby_gem: 5 }, req: [], bonus: { dmg: 1 } });
```

## 3. Справочник API (`GoldRush`)

### Состояние и ресурсы
| Вызов | Описание |
|---|---|
| `GoldRush.state` | Живой объект состояния игры. **Только чтение.** Полезные поля: `coins, ore, coal, ingot, diamond, gems, level, xp, stars, loc, stats{blocks,rounds,...}`. |
| `GoldRush.res.get(id)` | Сколько ресурса (`'coins'`, `'ore'`, `'ingot'`, любой предмет мода). |
| `GoldRush.res.add(id, n)` | Добавить (n<0 — отнять). Единственный честный способ выдать монеты. |
| `GoldRush.res.spend(id, n)` | Списать, если хватает. Возвращает `true/false`. |
| `GoldRush.res.has(id, n)` | Хватает ли. |
| `GoldRush.res.list()` | Все известные id ресурсов. |
| `GoldRush.level`, `.loc`, `.stars`, `.gems` | Быстрые геттеры (уровень, id локации, перекрут-монеты, изумруды). |
| `GoldRush.locations()` | `[{id,name,unlocked,done,progress,goal}]`. Локации: `forest, ice, desert, deep, sea, nether, end`. |
| `GoldRush.price(id)` | Текущая рыночная цена предмета или `null`. |
| `GoldRush.addXP(n)` | Выдать опыт. |

Основные ресурсы игры: `coins, ore (золотая руда), coal, ingot (золотой слиток), gblock, diamond, iron, ironIng, redstone, emerald (нефрит), gear, circuit, apple, eApple, pHaste, pLuck, pTime, wood, pumpkin, ice, sand, cactus, lapis, prism, sponge, quartz, glow, obs, chorus`. Изумруды (`gems`) — премиум-валюта, их нельзя добавлять модами.

### Регистрация контента

**`addItem({id, name, icon, price?, loc?, reserve?, inventory?})`** — предмет (ресурс).
`price` — если задан, предмет появится на рынке с этой базовой ценой. `loc` — id локации, после открытия которой товар виден на рынке. `inventory:false` — не показывать на складе.

**`addBlock({id, name, desc?, icon, hp, life, xp?, minLevel?, weights, drops?, coins?, hazard?, particles?, onSpawn?, onHit?, onBreak?, onExpire?})`** — новый блок, появляющийся на поле.
- `hp` — прочность (в ударах), `life` — сколько секунд блок живёт.
- `weights` — число (шанс везде) или объект `{ '*': 3, ice: 8 }` (по локациям; `'*'` — остальные). Для сравнения: золото ≈ 40, уголь ≈ 15, алмаз ≈ 2.
- `drops` — `{ предмет: [мин, макс, шанс?] }`, `coins` — `[мин, макс]` монет за блок.
- `hazard:true` — опасный блок: помощники и автодобытчик его не трогают, динамит его обезвреживает.
- Колбэки получают объект-контекст `c`: `{ block, type, x, y, player }`. В `onBreak` можно поставить `c.cancel = true`, чтобы отменить стандартную награду.
- Сам блок: `block.hp`, `block.life` (секунды до исчезновения), `block.type`.

**`addRecipe({id, group?, name?, icon?, cost, out, amount?, desc?, once?})`** — рецепт на верстаке (вкладка «Печь»). `cost` — `{ предмет: число }` (монеты в рецептах нельзя). `group` — заголовок секции (по умолчанию «Моды»). `once:true` — можно создать только один раз.

**`addTreeNode({id, name, desc?, icon?, branch?, req?, cost?, bonus?})`** — узел древа навыков. `req` — id узлов-предпосылок. `cost` — `{coins:…, предмет:…}`. `bonus` — `{ ключ: число }` (см. «Бонусы»).

**`addUpgrade({id, name, desc?, icon?, max, cost(level), effect?(level), onBuy?(level), persist?})`** — многоуровневое улучшение в «Лавке». `cost(level)` возвращает `{coins:…}` для покупки следующего уровня (level — текущий, с 0). `effect(level)` возвращает `{ключ: число}` бонусов для текущего уровня. `persist:true` — улучшение сохраняется при перекрутке. Текущий уровень: `GoldRush.level_of(id)`.

**`addTab({id, title, icon?, render(el)})`** — новая вкладка нижнего меню. `title` до 10 символов. `render(el)` вызывается при каждом открытии вкладки: наполните `el` (DOM-элемент). Поддерживаются `GoldRush.h` и `GoldRush.ui`.

**`addPanel(slot, {title?, render(el)})`** — карточка внутри существующей вкладки. Слоты: `mine` (под полем), `furnace`, `market`, `shop`, `tree`, `prog` («Ещё»). `render` вызывается при каждой перерисовке вкладки.

**`addBonus(key, число | функция)`** — постоянный бонус. Функция вычисляется при пересчёте бонусов (`GoldRush.refreshBonuses()` пересчитывает вручную).

Ключи бонусов (складываются с бонусами древа): `dmg` (+урон), `ore` (+доля добычи руды, 0.15 = +15%), `coin` (+доля монет), `time` (+секунды раунда), `spawn` (+интенсивность появления блоков), `combo` (+длительность комбо, с), `clock` (+секунды за часы), `sell` (+доля к цене продажи), `spread` (−доля разницы покупки/продажи), `smelt` (−секунды плавки), `slots` (+печи), `cd` (−доля перезарядки умений), `pen` (−секунды штрафа TNT), `autoEff` (+эффективность автодобытчика), `green` (1 — зелёный TNT безвреден), `shield` (1 — красный TNT отнимает половину времени вместо конца), `defuse` (1 — фиолетовый TNT штрафует вдвое меньше). Можно придумывать свои ключи и читать их через `GoldRush.bonus('ключ')`.

**Иконки** (`icon` в addItem/addBlock/addTreeNode/…): одна из форм
- `'#rrggbb'` — значок по умолчанию (самоцвет для предмета, блок для блока);
- `{ gem|ore|block|nugget|ingot|potion|apple: '#rrggbb' }` — готовые генераторы;
- `{ rows: [...16 строк по 16 символов], palette: { 'a': '#ff0000', ... } }` — пиксель-арт (`.` — прозрачно);
- `{ texture: 'data:image/png;base64,...' }` или `'https://…'` — своя картинка;
- строка с существующим ключом значка, например `'coin'`, `'gear'`, `'pick3'`, `'b_gold'`, `'diamond'`, `'ingot'`.

### События — `GoldRush.on(имя, функция)` (возвращает функцию отписки)
| Событие | Аргумент |
|---|---|
| `ready` | — (после загрузки всех модов) |
| `second` | — (раз в секунду, всегда) |
| `tick` | `dt` секунд (каждый кадр, **только во время раунда**) |
| `roundStart` | объект раунда |
| `roundEnd` | итоги `{coins, ore, coal, diamond, blocks, xp, extra}` |
| `blockSpawn` | блок |
| `blockHit` | `{block, type, damage, player}` |
| `blockBreak` | `{block, type, x, y, player}` |
| `blockExpire` | `{block, type, x, y}` (блок исчез сам) |
| `drop` | `{type, drop, coins, xp}` — **можно менять** `drop`, `coins`, `xp` до выдачи награды |
| `travel` | `(новаяЛокация, старая)` |
| `tab` | id открытой вкладки |
| `levelUp` | новый уровень |
| `craft` | `(idРецепта, количество)` |

### Раунд — `GoldRush.round`
`active` (идёт ли раунд), `timeLeft`, `combo`, `blocks` (живые блоки), `addTime(сек)`, `spawn(тип?)` (создать блок; без типа — случайный; вернёт `true/false`), `hit(блок, урон?)`, `start()`, `end()`, `blockTypes()`.

### Интерфейс и прочее
- `GoldRush.toast(текст, ключЗначка?)`, `GoldRush.sfx('coin'|'buy'|'err'|'level'|'boom'|'brk'|'start'|'end')`, `GoldRush.fmt(число)` (1.2K, 3.4M), `GoldRush.icon(ключ)` → HTML `<img>`, `GoldRush.css(текст)` — добавить CSS, `GoldRush.refresh()` — перерисовать текущую вкладку.
- Хранение: `GoldRush.storage.get(ключ, поУмолчанию)`, `.set(ключ, значение)`, `.remove(ключ)` — постоянное хранилище мода в LocalStorage (JSON). `GoldRush.data` — объект, который хранится **внутри сохранения игры** (попадает в экспорт, переживает перекрутку; мутируйте его свойства).
- `GoldRush.save()` — принудительно сохранить игру.

### Библиотека — `GoldRush.lib`
- Утилиты: `rnd(a,b)`, `ri(a,b)` (целое), `clamp(v,a,b)`, `pick(массив)`, `chance(p)`, `weighted([[значение, вес], …])`, `fmt(n)`, `shade('#hex', множитель)`, `rng(seed)`.
- `GoldRush.h(тег, свойства, ...дети)` — сборка DOM. Свойства: `class, style (строка или объект), text, html, dataset, onClick, onInput, …, прочие атрибуты`. Обработчики событий защищены от ошибок.
- `GoldRush.ui` — готовые элементы в стиле игры: `card(заголовок, ...дети)`, `row({icon, title, sub, right})`, `button(текст, onClick, {cls:'gold'|'blue'|'red'|'em', disabled, icon})`, `btnrow(...кнопки)`, `bar(доля)` (у результата есть `.set(доля)`), `tag(текст)`, `small(текст)`, `icon(ключ)`, `costs({coins:100, ruby_gem:2})`.
- `GoldRush.lib.tex` — генераторы картинок (возвращают data-URI): `pixels(rows, palette)`, `block(seed,{b:[цвета],sp:[цвета],n})`, `ore(seed,[4 цвета])`, `gem(светлый,средний,тёмный)`, `nugget(seed,[3 цвета])`, `ingot(палитра)`, `potion(цвет1,цвет2)`, `solid(цвет)`.

## 4. Примеры

### Вкладка со счётчиком и улучшением
```js
// @id counter
// @name Счётчик
const gr = GoldRush, { h, ui } = gr;
let breaks = gr.storage.get('breaks', 0);
gr.on('blockBreak', c => { if (c.player) { breaks++; gr.storage.set('breaks', breaks); } });
gr.addTab({ id: 'counter', title: 'Счёт', icon: 'star', render(el) {
  el.appendChild(ui.card('Мои удары',
    h('div', {}, 'Сломано игроком: ' + breaks),
    ui.button('Подарок 500 монет', () => { gr.res.add('coins', 500); gr.refresh(); }, { cls: 'gold' })));
}});
gr.addUpgrade({ id: 'power', name: 'Тренировка', desc: '+1 к урону за уровень', max: 5,
  cost: l => ({ coins: 1500 * Math.pow(2, l) }), effect: l => ({ dmg: l }) });
```

### Бонус времени за фиолетовую бомбу и свой «часовой» блок
```js
// @id timeblock
// @name Песочные часы
const gr = GoldRush;
gr.addBlock({ id: 'sand_clock', name: 'Песочные часы', desc: '+5 секунд', icon: { block: '#e8c35a' },
  hp: 2, life: 2.2, weights: { '*': 3 },
  onBreak(c) { gr.round.addTime(5); gr.toast('+5 с', 'clock'); c.cancel = true; } });
```

### Бонус к награде через событие drop
```js
// @id luckycoins
// @name Удачливые монеты
GoldRush.on('drop', d => { if (Math.random() < 0.05) d.coins *= 3; });
```

## 5. Безопасность и сбои
- Мод имеет полный доступ к странице: ставьте только проверенный код.
- Если мод завис при запуске, он автоматически отключается при следующем открытии игры. Если игра не открывается вообще, добавьте к адресу `#nomods` — моды не запустятся.
- Античит игры сравнивает монеты и изумруды с учётом начислений. Мод, который пишет в `state.coins` напрямую, будет наказан обнулением. Используйте `res.add`.
